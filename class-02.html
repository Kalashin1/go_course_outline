Lesson content

Concepts we will cover

Control flow

if/else, switch, for as Go's loop, break and continue; no parentheses required around conditions.

Collections

Arrays versus slices; append and len; iterating with range; maps for key/value data; map lookup and comma-ok.

Functions

Function declarations; typed parameters; return types; multiple returns; named returns as a concept; scope.

Error-return preview

The common (value, error) function shape and why Go asks callers to check errors explicitly.

Code walkthroughs

Learn by reading and running Go code

Type these examples into your own project rather than only copying them. Run each one, change a value, predict the output, and run it again. Some examples are focused fragments; the notes explain any imports or surrounding code they need.

Conditionals and loops

Example 1
package main

import "fmt"

func main() {
	scores := []int{72, 45, 90, 58}
	for index, score := range scores {
		if score >= 60 {
			fmt.Printf("%d: pass (%d)\n", index, score)
		} else {
			fmt.Printf("%d: retry (%d)\n", index, score)
		}
	}
}
Teaching note: Go uses for for every loop style. range gives each slice index and value; if/else branches do not require parentheses around the condition.

Functions and maps

Example 2
package main

import "fmt"

func average(values []float64) float64 {
	var total float64
	for _, value := range values {
		total += value
	}
	if len(values) == 0 {
		return 0
	}
	return total / float64(len(values))
}

func main() {
	prices := map[string]float64{"book": 12.5, "pen": 2}
	fmt.Println("Book price:", prices["book"])
	fmt.Println("Average:", average([]float64{10, 20, 30}))
}
Teaching note: A function declares parameter and return types. A map stores key/value pairs; a slice is a flexible view over a sequence. The conversion to float64 is explicit.

Practice while you learn

After each example, make one deliberate change and explain what changed. If the compiler reports an error, read the file name and line number, fix one issue at a time, then run the example again.

Guided practice

Let's build something together

End-of-class challenge

Your turn to prove your understanding

Build a **simple expense summary program**. Keep at least five expenses in a slice, use a map to group or label categories, and write separate functions to calculate the total, average expense and largest expense. Print a summary and handle an empty slice without dividing by zero.

Submission checklist

  • □Uses if/else, a for loop and range at least once.
  • □Uses both a slice and a map for sensible purposes.
  • □Has at least three small functions with typed parameters/returns.
  • □Handles the empty-data case safely and produces correct totals.

Optional stretch goal

Allow the learner to add another expense and category, then recalculate the report.
