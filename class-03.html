Learning objectives

By the end of this class, you should be able to

  • ✓Define structs and create values using named fields.
  • ✓Add methods to a type and understand pointer receivers at a beginner level.
  • ✓Describe how Go interfaces are satisfied implicitly.
  • ✓Return, inspect and handle errors using the standard Go pattern.
  • ✓Organize code into packages and understand module imports.

Lesson content

Concepts we will cover

Structs and composition

Define structs, fields, struct literals, nested structs and composition instead of class inheritance.

Methods and pointers

Value versus pointer receivers; when a method should modify a value; basic pointer syntax and nil awareness.

Interfaces

Define small behavior contracts; implicit satisfaction; use interfaces to make code easier to test and change.

Errors

The error type; errors.New and fmt.Errorf; checking if err != nil; returning errors to callers.

Packages and modules

Package naming, exported identifiers, imports, go mod tidy and standard library discovery.

Code walkthroughs

Learn by reading and running Go code

Type these examples into your own project rather than only copying them. Run each one, change a value, predict the output, and run it again. Some examples are focused fragments; the notes explain any imports or surrounding code they need.

Structs and methods

Example 1
package main

import "fmt"

type User struct {
	Name  string
	Email string
}

func (u User) DisplayName() string {
	return u.Name + " <" + u.Email + ">"
}

func main() {
	u := User{Name: "Ada", Email: "ada@example.com"}
	fmt.Println(u.DisplayName())
}
Teaching note: A struct groups related fields. DisplayName is a method with a value receiver, so it can read the User without changing it.

Interfaces and explicit errors

Example 2
package main

import (
	"errors"
	"fmt"
)

type Greeter interface {
	Greet() string
}

type Member struct{ Name string }
func (m Member) Greet() string { return "Hello, " + m.Name }

func findName(name string) (string, error) {
	if name == "" {
		return "", errors.New("name is required")
	}
	return name, nil
}

func main() {
	var g Greeter = Member{Name: "Ada"}
	fmt.Println(g.Greet())
	name, err := findName("")
	if err != nil { fmt.Println("Error:", err); return }
	fmt.Println(name)
}
Teaching note: A type satisfies an interface by implementing its methods—there is no implements keyword. Go commonly returns errors as values; callers should check them.

Practice while you learn

After each example, make one deliberate change and explain what changed. If the compiler reports an error, read the file name and line number, fix one issue at a time, then run the example again.

Guided practice

Let's build something together

Create a Task struct with ID, Title and Done fields. Add a MarkDone method and a function that rejects an empty title by returning an error.

End-of-class challenge

Your turn to prove your understanding

Build a **package-based task manager**. Define a Task struct, add methods to complete and describe a task, and create functions to add and list tasks. Reject blank titles with a returned error. Put task-related code in its own package and call it from package main.

Submission checklist

  • □Uses a struct with at least three fields and at least one method.
  • □Demonstrates a pointer receiver or clearly explains why one is not needed.
  • □Returns and checks an error for invalid task input.
  • □Separates main program code from task domain code in a Go module.

Optional stretch goal

Define a small interface for a task store and create an in-memory implementation. This prepares the learner for database-backed storage.
