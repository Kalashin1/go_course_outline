The practical learning roadmap

Go from JavaScript developer to Go backend builder.

A focused three-week course for an early-career developer who already understands JavaScript, TypeScript and Node.js, and is ready to build with Go.

Starting point

JavaScript / TypeScript

Understands variables, functions, objects, async code and Node.js basics.

Main outcome

Build and explain

A small, maintainable REST API backed by MongoDB, with tests and sensible error handling.

Second outcome

Ship a CLI tool

A command-line app that accepts input, performs useful work and handles failures cleanly.

Course structure

Three weeks, three milestones

Each week contains 3 classes of 2 hours each (6 guided hours per week). Every class has its own lesson page, guided practice and an end-of-class challenge.

Week 01

Go fundamentals and developer workflow

Milestone: Go basics

Topics to cover

  • 1. Getting started: what Go is, where it is used, installing Go, editor setup, go version, go run and go build.
  • 2. Syntax and types: packages, main, imports, variables, constants, type inference, basic types and zero values.
  • 3. Control flow and collections: if, for, switch, arrays, slices and maps.
  • 4. Functions and errors: parameters, return values, multiple returns, scope, pointers at an introductory level and explicit error checks.
  • 5. Structuring Go programs: structs, methods, interfaces, packages, modules, dependency management and formatting with gofmt.

Practice and checkpoint

  • Translate small JavaScript functions into Go.
  • Create a contact or inventory model using structs.
  • Write functions that return and handle errors.
  • Split a small program into packages.

Deliverable

A small Go console program

A menu-driven contact or task manager using slices, structs and functions.

Week 02

REST API development with MongoDB

Milestone: working API

Topics to cover

  • 1. HTTP in Go: net/http, handlers, routes, request and response objects, status codes and JSON encoding/decoding.
  • 2. API design: REST principles, resource naming, GET/POST/PATCH/DELETE, request validation and consistent response shapes.
  • 3. MongoDB connection: MongoDB concepts, local or hosted database setup, official Go driver, connection lifecycle and configuration via environment variables.
  • 4. CRUD operations: collections, BSON, insert, find, update and delete; ObjectID handling and mapping documents to Go structs.
  • 5. Reliability: context and timeouts, error responses, logging, project structure, configuration and API testing with curl or an API client.

Practice and checkpoint

  • Build one handler and return JSON.
  • Connect the app to MongoDB.
  • Implement and test CRUD endpoints.
  • Validate bad input and return appropriate status codes.

Deliverable

Task Manager REST API

An API with create, list, get-by-ID, update and delete endpoints, persisting data in MongoDB.

Week 03

CLI applications, testing and finishing

Milestone: CLI + polished API

Topics to cover

  • 1. Command-line foundations: terminal input/output, flags and arguments with the standard library, exit codes and helpful usage messages.
  • 2. Files and configuration: reading/writing files, JSON files, environment variables, paths and handling filesystem errors.
  • 3. CLI design: commands and subcommands, separating business logic from the command interface, and when a CLI framework is useful.
  • 4. Testing and quality: testing package, table-driven tests, testable functions, go test, go vet and race detection basics.
  • 5. Build and release: compile for the target platform, project documentation, README, configuration examples and basic deployment considerations.

Practice and checkpoint

  • Build a CLI that accepts flags.
  • Read and write structured JSON data.
  • Add tests for core functions.
  • Build an executable and document how to use it.

Deliverable

A useful CLI application

For example, a task tracker or personal expense logger with add/list/update/delete commands and file persistence.

Learning outcomes

What learners should be able to do

  • ✓ Read and write basic, idiomatic Go code.
  • ✓ Explain Go's types, structs, interfaces, packages and error-handling approach.
  • ✓ Build and test HTTP REST endpoints.
  • ✓ Connect a Go service to MongoDB and perform CRUD operations.
  • ✓ Build a practical CLI application that accepts commands or flags.
  • ✓ Format, test, build and document a small Go project independently.

Suggested tools

Go toolchain

Go compiler, go command, gofmt, go test and go vet.

Editor

VS Code with the official Go extension, or another Go-friendly editor.

Database

MongoDB Community Server or MongoDB Atlas, plus the official Go driver.

API practice

curl, Postman or Bruno for sending HTTP requests.

Version control

Git and a remote repository for checkpoints and code review.

Teaching approach

Keep the learning practical

Explain

Introduce one concept at a time and relate it to the learner's Node.js experience.

Demonstrate

Live-code a small example, explain decisions and show common mistakes.

Build

Let the learner implement a variation, test it, explain it and commit the result.

Scope note: Three weeks is an intensive introduction, not mastery of the Go ecosystem. Prioritize fundamentals and working projects; treat advanced concurrency, authentication, deployment automation and production observability as follow-on study.
