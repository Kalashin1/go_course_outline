Code walkthroughs

Learn by reading and running Go code

Type these examples into your own project rather than only copying them. Run each one, change a value, predict the output, and run it again. Some examples are focused fragments; the notes explain any imports or surrounding code they need.

Connect to MongoDB (official Go driver v2)

Example 1
package main

import (
	"context"
	"log"
	"time"

	"go.mongodb.org/mongo-driver/v2/mongo"
	"go.mongodb.org/mongo-driver/v2/mongo/options"
)

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
	defer cancel()

	client, err := mongo.Connect(options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil { log.Fatal(err) }
	defer func() { _ = client.Disconnect(context.Background()) }()

	if err := client.Ping(ctx, nil); err != nil { log.Fatal(err) }
	log.Println("Connected to MongoDB")
}
Teaching note: Install the driver with go get go.mongodb.org/mongo-driver/v2. Keep the URI in an environment variable in real projects; never commit credentials.

Insert and read a document

Example 2
type User struct {
	Name  string `bson:"name"`
	Email string `bson:"email"`
}

collection := client.Database("course_db").Collection("users")
result, err := collection.InsertOne(ctx, User{
	Name: "Ada", Email: "ada@example.com",
})
if err != nil { log.Fatal(err) }
log.Println("Inserted ID:", result.InsertedID)

var saved User
err = collection.FindOne(ctx, bson.M{"email": "ada@example.com"}).Decode(&saved)
if err != nil { log.Fatal(err) }
log.Println("Found:", saved.Name)
Teaching note: This focused fragment belongs inside a function after client is connected. Add the bson import: go.mongodb.org/mongo-driver/v2/bson. Explain InsertOne, FindOne, Decode and checking errors.

  • □Implements all five CRUD actions through API routes or repository functions.

  • □Does not hard-code or commit database credentials.
