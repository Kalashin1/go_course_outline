01 / The big picture

What exactly is Go?

Go (also called Golang) is an open-source, statically typed, compiled programming language. It was designed to make it straightforward to build reliable software, especially network services and developer tools.

⚙️

Compiled

Go source code is compiled into an executable program. You can often ship that binary without asking the user to install a Go runtime.

🧭

Statically typed

Types are checked before the program runs. The compiler catches many mistakes early and helps tools understand your code.

🧰

Batteries included

The standard library includes useful packages for HTTP servers, JSON, files, testing, cryptography and more.

02 / A familiar starting point

Go compared with JavaScript

You already understand variables, functions, objects, modules and asynchronous work. Those ideas still matter in Go, but the syntax and some design choices are different.

  • ●No implicit dynamic typing: Go values have declared or inferred static types.
  • ●Errors are values: many functions return an error that you check explicitly.
  • ●Composition over class hierarchies: Go uses structs and interfaces rather than traditional classes and inheritance.
  • ●Concurrency is built in: goroutines and channels provide tools for concurrent work.
Same idea, different syntaxJavaScript → Go

JavaScript

function greet(name) {
  return `Hello, ${name}`;
}

Go

func greet(name string) string {
    return "Hello, " + name
}

Notice the parameter type and return type. Go makes these part of the function signature.

03 / Core building blocks

The concepts you will learn first

Variables & types

Understand var, :=, constants, strings, booleans and numbers.

Control flow

Use if, for and switch to control program behavior.

Functions & errors

Return multiple values and handle errors deliberately.

Structs & interfaces

Model data and define behavior with small, implicit interfaces.

Packages & modules

Organize code, manage dependencies with Go modules and use the standard library.

Goroutines & channels

Get an introduction to concurrency and safe communication between tasks.
